메일 속 사진은 이 저장소의 GitHub Pages 주소(`https://dudcks1221.github.io/sefc-newsletter-images/…`)로 불러옵니다.

- 이미 발송한 메일이 이 주소를 쓰므로 파일을 지우거나 옮기지 마세요.
